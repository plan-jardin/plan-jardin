# plan jardin

A small garden planning app built with vanilla JavaScript and Vite.

## Getting started

```sh
npm install
npm run dev
```

Vite serves the app locally with hot module replacement. Run `npm run build` to create the production site in `dist/`, or `npm run preview` to serve that build locally.

## Deploying to GitHub Pages

The workflow in `.github/workflows/pages.yml` builds and deploys the site on every push to `main`. It also supports manual runs from the Actions tab. In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**. The build automatically uses the repository name as the project-site base path.
